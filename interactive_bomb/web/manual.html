00 / RELEVÉ

Lire la plaque

La petite plaque au centre bas du boîtier porte le numéro de série, le nombre de cellules (1 à 4), le bus (A, B ou C) et le type.

Dans AB-4827, les quatre chiffres sont 4827 et le dernier chiffre est 7. Les deux lettres identifient le boîtier et n'entrent pas dans les calculs.

Appuyer sur E pour examiner. Le survol indique la pièce et sa valeur actuelle ; les valeurs affichées viennent de l'état accepté par le serveur.

Le compte à rebours continue pendant la lecture du manuel. Les interrupteurs et molettes ne démarrent pas forcément à zéro.
01 / FIL

Un seul fil à couper

Dernier chiffre de sérieFil
0 ou 5Rouge

2 ou 7Vert

Les quatre autres fils restent intacts. Un mauvais fil provoque immédiatement l'échec du puzzle.

02 / INTERRUPTEURS

Configurer les deux états

Interrupteur 1, à gauche : ON si le dernier chiffre est pair (0, 2, 4, 6, 8) ; OFF sinon.

Interrupteur 2, à droite : ON avec 3 ou 4 cellules ; OFF avec 1 ou 2.

Un clic inverse l'état. Utiliser l'indication ON/OFF au survol pour contrôler le résultat.

Lire l'angle au survol, dans le panneau d'inspection ou sur l'écran du boîtier. Attendre la mise à jour entre les clics.

04 / CLAVIER

Construire le code à six chiffres

  1. Inverser les quatre chiffres de série, en conservant les zéros.
  2. Ajouter le chiffre du type ci-dessous.
  3. Ajouter le nombre de cellules.
TypeChiffre
Explosive1
Bio2
Nuke3
EMP4

Saisir les six chiffres puis #. * efface toute la saisie. La validation exige simultanément le bon fil, les deux états et les deux angles.

Une validation incorrecte efface le code et retire 25 % de stabilité. Quatre erreurs ou l'expiration du timer font échouer le puzzle.

EXEMPLE DE LECTURE

BIO · AB-4827 · 3 cellules · bus B

Dernier chiffre 7 → fil vert, interrupteur 1 OFF.
3 cellules → interrupteur 2 ON.

Molette 1 : 210° · Molette 2 : 150°.
4827 inversé donne 7284, puis type 2 et cellules 3 → 728423.
